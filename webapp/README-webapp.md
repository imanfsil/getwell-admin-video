# Getwell Weight Loss Admin — the web app

This folder is the application itself, exactly as supplied and **unchanged by
the video work**: the same HTML pages, `app.js`, `styles.css`, `Code.gs`
backend script, UI, pages and functionality.

It is included here so the project and the film that presents it live
together, and so the narration can be checked against the real features. The
Remotion render at the repository root does **not** read anything from this
folder — deleting it will not affect the video.
