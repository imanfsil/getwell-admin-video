# Getwell Admin Video

A Remotion project for a promotional video showcasing the Getwell Weight Loss Admin web app.

## Preview locally

```bash
npm install
npm run preview
```

## Render MP4 locally

```bash
npm run render
```

Output: `out/getwell-admin-promo.mp4`

## GitHub Actions

Open **Actions → Render Getwell Video → Run workflow**.
The finished MP4 is uploaded as the `getwell-admin-promo` artifact.

The original Getwell web app source is included under `public/app/` for reference and future integration.
